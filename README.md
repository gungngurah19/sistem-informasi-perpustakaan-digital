# Sistem Informasi Perpustakaan Digital

## Deskripsi

Sistem Informasi Perpustakaan Digital merupakan sistem yang dirancang untuk membantu pengelolaan data perpustakaan secara terkomputerisasi. Sistem ini mencakup pengelolaan data buku, anggota perpustakaan, peminjaman, pengembalian, dan pembuatan laporan.

## Tujuan

Tujuan pengembangan Sistem Informasi Perpustakaan Digital adalah:

- Mempermudah pengelolaan data perpustakaan.
- Mempercepat pencarian informasi buku.
- Membantu pencatatan peminjaman dan pengembalian buku.
- Mempermudah pembuatan laporan perpustakaan.

## Pengguna Sistem

Sistem Informasi Perpustakaan Digital ditujukan untuk beberapa jenis pengguna, yaitu:

- **Admin Perpustakaan**: Mengelola data dan pengaturan sistem.
- **Petugas Perpustakaan**: Mengelola data buku serta transaksi peminjaman dan pengembalian.
- **Anggota Perpustakaan**: Mengakses informasi buku dan layanan perpustakaan sesuai dengan hak akses yang diberikan.
- **Kepala Perpustakaan**: Memantau aktivitas dan melihat laporan perpustakaan.

## Teknologi Pendukung

Teknologi yang digunakan untuk mendukung pengelolaan dokumentasi proyek meliputi:

- **GitHub**: Digunakan sebagai media penyimpanan dokumentasi berbasis cloud, pengelolaan repository, dan kolaborasi.
- **Git**: Digunakan untuk mengelola versi dokumentasi serta mencatat riwayat perubahan.

## Pengelolaan Versi

Pengelolaan versi dilakukan menggunakan Git untuk mencatat setiap perubahan dokumentasi. Perubahan disimpan melalui proses commit dan dapat diunggah ke repository GitHub sehingga riwayat pembaruan dapat ditelusuri.

Contoh perintah Git untuk memperbarui dokumentasi:

```bash
git add .
git commit -m "Memperbarui dokumentasi"
git push origin main
```

Keterangan:

- `git add .`: Menambahkan perubahan ke staging area.
- `git commit -m "Memperbarui dokumentasi"`: Menyimpan perubahan ke dalam riwayat Git.
- `git push origin main`: Mengunggah perubahan ke branch `main` pada repository GitHub.
